# Programming Fundamentals

A foundation module for understanding how programs are designed, executed, and reasoned about before moving deeper into Java and Data Structures & Algorithms.

## Module Overview

This module covers the fundamental ideas required to understand programming before focusing on Java syntax or DSA implementation.

## Learning Path

### 1. Introduction to Programming

- What is programming?
- What is a program?
- Role of a programmer / developer
- Problem → Logic / Algorithm → Code → Execution → Output
- Source code and executable instructions
- Syntax vs Semantics vs Logic
- Compile Time vs Runtime
- Common programming errors

### 2. Types of Programming Languages

- Machine Language
- Assembly Language
- High-Level Languages
- Low-Level vs High-Level Languages
- Compiler
- Interpreter
- Where Java fits
- Is Java compiled or interpreted?

### 3. Memory Fundamentals

- Why programs need memory
- Variables and values
- Primitive values
- References and objects
- Stack and Heap — introductory model
- Primitive vs Reference types
- Garbage Collection
- Java references vs raw pointers

### 4. Flow of a Program

- Statement execution order
- Sequential flow
- Decisions / branching
- Repetition / loops
- Method call flow
- Input → Processing → Output
- Manual program tracing

### 5. Flowcharts

- What is a flowchart?
- Why use flowcharts?
- Start / End
- Input / Output
- Process
- Decision
- Flow arrows
- Representing conditions
- Representing loops
- Problem → Flowchart

### 6. Pseudocode

- What is pseudocode?
- Pseudocode vs programming code
- Characteristics of good pseudocode
- Decisions in pseudocode
- Loops in pseudocode
- Breaking problems into logical steps
- Pseudocode → Dry Run
- Pseudocode → Java

## Learning Method

Each concept follows:

**Learn → Understand Why → Concept Check → Predict → Dry Run → Implement → Test → Analyze → Explain → Document → Practice → Revise**

## Module Goal

By the end of this module, I should be able to take a simple problem and reason through:

**Problem → Understand → Logic → Flowchart / Pseudocode → Dry Run → Java Implementation → Test → Explain**
